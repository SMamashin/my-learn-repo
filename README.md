# 🧪 Лабораторная работа: GitBash + GitHub

Учебный репозиторий для выполнения лабораторных работ по изучению систем контроля версий.

## 🎯 Цели работы
* **Создать** локальный репозиторий с помощью инструментов `GitBash` и `GitGui`.
* **Заполнить** репозиторий базовыми заготовочными файлами проекта.
* **Связать** локальный репозиторий с удаленным репозиторием на `GitHub`.

## 📁 Структура репозитория
* 📄 `index.html` — главная страница (разметка веб-страницы)
* 📜 `script.js` — файл для интерактивных скриптов
* 📁 `styles/` — папка со стилями оформления
  * 🎨 `styles.css` — таблицы стилей CSS
* 📁 `assets/` — папка для медиафайлов и ресурсов
  * 🖼️ `.gitkeep` — технический файл для сохранения пустой папки в Git
